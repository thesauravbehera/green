## 🚀 HOW TO RUN

### **Method 1: Update index.html**
```html
<!-- Change your root index.html -->
<script type="module" src="/mobile-app/index.tsx"></script>
```
Then: `npm run dev`

### **Method 2: Browser DevTools**
1. Run existing app: `npm run dev`
2. Open DevTools (F12)
3. Toggle device toolbar (Ctrl+Shift+M)
4. Select "iPhone 12 Pro"
5. Navigate through mobile app
